# Randon One Block 1.1.0.0

## The Echo

The break that takes your team to **100,000 Randon Mined** places **The Echo** on the center block, once. It is not in the random pool. Online teammates receive an **Echo Seal**. The next break is a normal roll again.

## Endgame path

1. **Quest book** — finish chapters to unlock mod pools into the center block.
2. **Randon Mined** — 500 BBL Utility, choice at 1,000 and 5,000, Easy Ore Generation at 2,500.
3. **The Atlas** — unique center rolls fill a curated endgame set. Completing the active set grants the **Atlas Seal**.
4. **The Echo** — 50,000 is “Echo Approaches”. 100,000 places The Echo.
5. **The Randon Ending** — completes when the team has both the Atlas Seal and the Echo Seal, in either order.

New quest tab: **The Echo** (opens from Getting Started → Randon Mined).

Restart the instance once so The Echo block registers.
