# Randon One Block 1.1.0.1

## Light Level Overlay

**Light Level Overlay** marks blocks where mobs can spawn. Press **F7** to turn the overlay on or off.

More Overlays also uses **F7** for its light overlay. If F7 still toggles More Overlays, open Controls and give Light Level Overlay its own key.
