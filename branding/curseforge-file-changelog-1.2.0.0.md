# Randon One Block 1.2.0.0

## Spawn lobby

New worlds start on a **Randon lobby** instead of the default Haven spawn island.

- The sign wall greets you and explains islands and teams.
- Step on the stone plate in front of the wall. It creates your island with `/havensb island create oneblock_island <your name>`.
- You can still type that command yourself, and use **J** or `/havensb team` for invites.

Worlds created before this version keep the old lobby. Make a new world to see this island.

Playtest confirmed.

The Echo, the Randon Atlas, and The Randon Ending are unchanged.
