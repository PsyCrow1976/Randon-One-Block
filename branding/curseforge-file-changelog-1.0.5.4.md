# Randon One Block 1.0.5.4

## Quest → random-block pool unlocks

Finish the entry quest for a mod and that mod’s blocks can roll from your team’s center block.

| Quest | Unlocks |
|-------|---------|
| Iron Furnace | Iron Furnaces |
| Animal Cage | Animal Pens |
| Obtain Villager | Easy Villagers |
| Obtain Piglin | Easy Piglins |
| Grains of Infinity | Ender IO |
| Cooking for Blockheads (recipe book) | Cooking for Blockheads |
| Silicon | Refined Storage |
| Dielectric Paste | Powah |
| Prosperity Shard | Mystical Agriculture **+** Agradditions **+** Automation |

Still works from earlier releases: Leather Backpack → Sophisticated Storage; Compressed Dirt → Ex Deorum; Philosopher’s Stone / The Red Rock → Equivox.

**After updating:** `/reload`, complete the quest (or re-login). Use `/randomblock pools list` to confirm.

## Mods

Same **85 mods** as **1.0.5.3** (Minecraft **26.1.2** / NeoForge **26.1.2.94**). No jar version changes in this patch — unlocks and quest text only.

## Known issue

Equivox Philosopher’s Stone world-transmutation can still crash until Equivox is rebuilt for current NeoForge.
