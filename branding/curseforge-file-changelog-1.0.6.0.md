# Randon One Block 1.0.6.0

## Headline: Randon Atlas

Unique blocks from your **center random block** are tracked per island team. A curated **endgame set** (~66 blocks) is the collection goal.

| Feature | Details |
|---------|---------|
| Progress | `/randomblock atlas` — owned/active % + unique roll count |
| Missing | `/randomblock atlas missing [mod]` |
| Quest book | New tab **The Atlas** — one quest per endgame block (**10 XP**); auto-completes on center roll |
| Seal | **Atlas Seal** (`kubejs:atlas_seal`) once when the active set is complete |
| Unlock rule | Entries for locked mod pools stay inactive until that pool is unlocked |

Also: chat toast when a new endgame-set page is discovered.

## Still included (from 1.0.5.6)
